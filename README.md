# [Giraffe](https://giraffe.wiki/)

Code for the official [giraffe.wiki](https://giraffe.wiki) website.

The website targets .NET 8 and uses Giraffe `8.3.0` and
Giraffe.ViewEngine `2.0.0-alpha-1` (including the latest published prerelease).
Build it with `dotnet build -c Release src/Giraffe.Website/Giraffe.Website.fsproj`.
